# MapleStory-Server 业务能力索引

## 玩家生命周期

| 能力 | 描述 |
|---|---|
| 账号认证 | 密码登录、合法凭据自动注册（BCrypt cost 12）、TOS、PIN/PIC 验证、HWID/MAC 绑定、多客户端检测 |
| 角色管理 | 创建/删除角色（普通新角色 STR/DEX/INT/LUK 均初始化为 20）、角色列表、角色槽位 |
| 登录流程 | 登录服务器（8484）→ 世界选择 → 频道选择 → 进入游戏；标准 `PLAYER_DC` 可从登录服或频道服主动登出并清理在线状态 |

## 角色成长

| 能力 | 描述 |
|---|---|
| 属性分配 | STR/DEX/INT/LUK 自动/手动分配、HP/MP 提升 |
| 职业转职 | 初级 → 一转 → 二转 → 三转 → 四转，54 个职业分支 |
| 技能系统 | 技能学习/升级、SP 分配、技能效果（Buff/攻击/被动）、冷却 |
| 经验升级 | 经验获取/倍率、等级奖励、经验表、经验券 |

## 战斗系统

| 能力 | 描述 |
|---|---|
| 近战攻击 | 战士/骑士/海盗近距离伤害计算 |
| 远程攻击 | 弓手/刺客/枪手远程伤害计算 |
| 魔法攻击 | 法师魔法伤害计算、元素属性 |
| 怪物 AI | 怪物巡逻/追击/攻击、仇恨控制器、技能使用 |
| 受伤/死亡 | 玩家受伤、死亡惩罚、买活机制 |

## 社交系统

| 能力 | 描述 |
|---|---|
| 组队 | 创建/加入/退出/踢人、队伍聊天、队伍buff |
| 公会 | 创建/解散/升级公会、成员管理、公会 BB、公会联盟 |
| 好友列表 | 添加/删除好友、在线状态 |
| 家庭系统 | 家庭关系、传承效果 |
| 结婚 | 结婚预约/仪式/戒指/离婚 |

## 经济系统

| 能力 | 描述 |
|---|---|
| 交易 | 玩家间面对面交易 |
| 商店 | NPC 商店买卖 |
| 自由市场 | 玩家商店、雇佣商人 |
| 储蓄箱 | 跨角色共享存储 |
| 枫叶谷 | 扭蛋机（按城镇分表） |

## 地图与移动

| 能力 | 描述 |
|---|---|
| 地图切换 | 传送门移动、脚本传送门、VIP 传送 |
| 地图实体 | 玩家/怪物/NPC/反应堆/召唤物/掉落物 |
| 怪物重生 | 出生点定时重生、地图实体清理 |
| 迷你副本 | 矿山/森林/BOSS 副本 |

## 任务与事件

| 能力 | 描述 |
|---|---|

| 远征队 | BOSS 远征（扎昆/鱼王/黑龙王等） |
